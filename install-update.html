How to install ​

To install the plugin from CodeCanyon, simply upload the plugin ZIP file to your site via Plugins ▹ Add New ▹ Upload Plugin.

Alternatively, unzip the plugin ZIP file and upload the resulting folder to your site's /wp-content/plugins/ directory. Don't forget to activate it through the Plugins menu in your WordPress dashboard.

Upgrading from the Lite version ​

The lite version and full version plugins operate independently. In other words, only one of them can and should be installed at the same time.

If you have the lite version installed, installing the full version will deactivate it. You can safely uninstall the lite version before or after installing the full version. Your attribute stock data will not be deleted (see Deleting database data below).

How to update ​

Automatic updates can be enabled in WordPress by authorizing your Envato account.

You can authorize as many sites as you have licenses for on the same Envato account: each regular license activates one site, while an extended license activates unlimited sites. Simply click Authorize with Envato on each site and the available licenses will be used automatically. If all your license slots are already in use, you'll be asked to choose which activated site to remove so the new site can take its place.

If updating manually, the procedure is the same as installing the plugin ZIP file.

Deleting database data ​

By default, when you uninstall WooCommerce Attribute Stock, all of the attribute stock data you've added will remain in your database. This safeguards against accidental data loss.

If you want all attribute stock data to be deleted when uninstalling, simply add the below line to your wp-config.php file before uninstalling the plugin:

php
define('MEWZ_DELETE_DATA', true);
